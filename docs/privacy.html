1. 収集・取り扱うデータと収集方法（What Data the App Collects & How It Is Collected - Guideline 5.1.1(i)）

本アプリ（Health Note / ヘルスノート）は、開発者側で管理・運用する外部データベースやWebサーバーを一切持たない完全サーバーレス設計を採用しています。アプリ内で取り扱われるデータとその取得方法は以下の通りです：

  • ユーザーによる手動入力データ（User-Entered Data）：食事記録（料理名・カロリー・PFC）、マイカルテの身体・生活習慣情報（年齢・性別・身長・体重・体脂肪率・活動レベル・睡眠時間・飲酒/喫煙/妊娠状況・食事制限・アレルギー・既往歴メモ）、服薬・サプリメント名、健康診断の検査数値、医療費記録、AIアドバイザー相談メッセージ。
  • カメラ・写真ライブラリからの選択画像（Optional User-Selected Photos）：食事写真、健康診断結果表の画像、医療費領収書・明細書の画像（お客様が自らカメラ撮影またはアルバムから選択した場合のみ取得）。
  • Apple HealthKit データ（Optional HealthKit Data）：お客様が明示的に許可した場合に限り、iOSのヘルスケア（HealthKit）から歩数・消費エネルギー・心拍数・睡眠時間・体重・体脂肪率を読み取り、食事のカロリー・PFCを書き込みます。
  • 広告配信に関する技術データ（Google AdMob SDK Telemetry）：デバイス識別子（ATT許可時のみIDFA）、おおよその位置情報、製品操作・広告表示データ、クラッシュ・パフォーマンス診断データ。

2. データの保存・同期およびすべての利用目的（Storage, All Uses of Data & Deletion）

【すべての利用目的（All Uses of Data）】：取得したデータは、(1) アプリ内での栄養・カロリー・PFCバランス計算およびグラフ表示、(2) マイカルテ・健診結果・医療費・服薬履歴の記録管理と月間カレンダー表示、(3) お客様が明示的に許可した場合の任意AI機能（栄養推定・書類OCR入力補助・食生活アドバイス生成）、および (4) 無料提供を維持するためのバナー広告配信（AdMob技術データのみ）の目的にのみ使用されます。

アプリ内で記録されたすべての個人・健康データは、お客様ご自身のiOS端末内、およびお客様個人のiCloudアカウント（Apple CloudKit Private Database）にのみ暗号化されて保存・同期されます。開発者のサーバーへ収集・送信・保存されることは一切ありません。

また、アプリ内の「設定」＞「全データを完全に初期化・削除」を実行することで、いつでもお客様ご自身の操作ですべての個人データ、保存設定、およびAIデータ送信の同意状態を完全に消去することができます。

3. Apple HealthKit（ヘルスケア）データの取り扱い（Guideline 5.1.3 準拠）

お客様が明示的にアクセスを許可した場合に限り、以下の項目についてApple HealthKitと連携します。

  • 読み取り項目：歩数、消費エネルギー（アクティブエネルギーおよび安静時エネルギー）、心拍数、睡眠分析（睡眠時間）、体重、体脂肪率（アプリ内のサマリ・マイカルテ・月間カレンダーへの表示目的のみに使用）
  • 書き込み項目：食事で記録した摂取エネルギー（kcal）、タンパク質（g）、脂質（g）、炭水化物（g）

【厳格事項（App Store Review Guideline 5.1.3 準拠）】：Apple HealthKitから取得した歩数・消費エネルギー・心拍数・睡眠データが第三者AI（Google Gemini API）や広告事業者へ送信されることは一切ありません。また、HealthKitから取得したいかなるデータも、広告配信・ターゲティング・マーケティング・データマイニング目的で使用することはなく、第三者へ売却・開示・共有することは一切ありません。

4. 第三者AIサービスへのデータ送信・送信先・事前同意および同等保護の確認（Third-Party AI Data Sharing & Equal Protection - Guideline 5.1.1(i) & 5.1.2(i)）

【初期状態（デフォルト）】：本アプリには内蔵APIキーがなく、初期状態ではいかなる個人データ・健康データも第三者AIサービスへ送信されません。

【事前の明示的な許可（Explicit User Permission before Sharing）】：お客様が任意でご自身の Google Gemini APIキーを「設定」画面で登録し、かつアプリ内の「第三者AIへのデータ送信の許可確認（Permission to Share Data with Third-Party AI）」モーダル画面にて送信データの内容と送信先を確認のうえ「データ送信を許可する（Allow）」を明示的に選択した場合にのみ、AI機能が有効化されます。お客様はいつでも「設定 ＞ AI拡張機能設定 ＞ 許可を取り消す」から同意を撤回できます。

  • データの送信先（Who the Data Is Sent To）：Google LLC（Google Gemini API / generativelanguage.googleapis.com）。開発者サーバーは一切経由せず、お客様の端末から Google LLC の API エンドポイントへ直接 HTTPS/TLS 暗号化通信で送信されます。
  • 送信されるデータの内容（What Data Will Be Sent）：
    • AIアドバイザー相談・本日のAI食事総括：入力した相談メッセージ、本日の食事記録（料理名・カロリー・PFC）、マイカルテの身体・生活習慣データ（年齢・性別・身長・体重/BMI・体脂肪率・活動レベル・睡眠時間・飲酒/喫煙/妊娠状況・食事制限・アレルギー・既往歴メモ）、登録中の服薬・サプリメント名、および直近の健康診断結果の検査数値サマリ（血圧・コレステロール・肝機能・血糖・HbA1c等の数値のみ）。
    • 写真AI自動読取（食事写真・健診結果表・医療費領収書/明細書）：お客様が自ら撮影またはアルバムから選択した対象画像データ。
    • 個人識別情報（PII）の除外：受診者氏名、ニックネーム、住所、生年月日、医療機関名（チャット送信時）、保険証記号・番号などの個人識別情報は送信データから除外・破棄されます。
  • 第三者による同等以上のデータ保護の確認（Confirmation of Same or Equal Protection by Third Parties）：本アプリがデータを共有・送信する第三者事業者（Google LLC：Google Gemini API および Google AdMob、ならびに Apple Inc.：iCloud / CloudKit）は、すべて業界標準の暗号化通信（HTTPS/TLS）および厳格なデータ保護規約・セキュリティ基準を遵守しており、本プライバシーポリシーに記載された基準および Apple App Store Review Guidelines（Guideline 5.1.1(i) & 5.1.2(i)）が求める水準と同等以上のプライバシーおよびセキュリティ保護（Same or Equal Protection）を提供していることを確認しています。

※Google AI Studioの無料枠（Free Tier）のAPIキーをご利用の場合、Googleの利用規約（Gemini API Additional Terms of Service）に基づき、送信されたデータがGoogleのモデル改善に利用される場合があります。学習利用を希望されない場合は、Google Cloudの有料従量課金プロジェクトで発行されたAPIキーをご利用いただくか、データ送信許可をオフにして手動記録機能をご利用ください。

5. 広告配信（Google AdMob）およびアプリ内課金（Proプラン）

本アプリを無料で提供・維持するため、第三者配信事業者である Google AdMob のバナー広告を利用しています。iOSのApp Tracking Transparency（ATT）フレームワークに基づき、お客様が許可された場合に限り広告識別子（IDFA）および広告データ（デバイスID・広告インタラクション）が広告の配信・最適化に利用されます。許可しない場合でもすべての機能をご利用いただけます。なお、Apple HealthKitのデータやアプリ内に記録された健康・食事・医療費情報が広告目的で利用・共有されることは一切ありません。

また、アプリ内課金（Apple StoreKit 2）による買い切りプラン「Health Note Pro」をご購入いただくことで、すべての広告を永久に非表示にすることができます。決済処理はAppleのApp Store決済基盤を通じて行われ、開発者がお客様のクレジットカード情報等を取得することはありません。

6. 医療免責事項および公的出典（医師法・薬機法・Guideline 1.4.1 準拠）

本アプリは、一般的な生活習慣の改善、健康維持および栄養・医療費記録をサポートするセルフケア・ツールであり、医療機器または医療提供サービスではありません。

  • 医師法第17条に基づく免責：本アプリ内のAIアドバイザー、食事栄養評価、健診数値表示その他のすべての情報は、医師、薬剤師、管理栄養士その他の医療専門家による医学的判断・診断・治療・処方・服薬指示の代替となるものではありません。体調に異変や痛みを感じた場合、持病をお持ちの場合、妊娠中または服薬中の方は、自己判断を行わず必ず主治医や専門医療機関にご相談ください。
  • 薬機法に基づく表記：本アプリで提示される栄養素、食材、サプリメント等に関する情報は一般的な栄養学・公的統計上の知見であり、特定の疾病の治療・予防や医薬品的な効能効果を保証・標榜するものではありません。
  • 公的出典・参考基準（Guideline 1.4.1 準拠）：本アプリ内のBMI計算式（体重kg ÷ [身長m]²、普通体重18.5〜25.0未満）、PFC栄養目標、健康診断項目の一般的な基準範囲、および医療費控除の集計目安は、以下の公的機関が公開する統計基準・案内情報に基づいています。
    • 厚生労働省「日本人の食事摂取基準」
    • 厚生労働省 健康情報サイト「BMI（体格指数）の算出と判定基準」
    • 文部科学省「日本食品標準成分表」
    • 厚生労働省「標準的な健診・保健指導プログラム」
    • 国税庁 タックスアンサー「No.1120 医療費を支払ったとき（医療費控除）」
